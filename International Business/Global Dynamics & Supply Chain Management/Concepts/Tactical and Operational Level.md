# Tactical and Operational Level

The assignment requires both: *"You will address this at both tactical and operational levels."* It is a scope instruction, and skipping one half is a visible gap.

- **Tactical** — the medium-term decisions that set the rules: which suppliers, which modes, which inventory policy, where stock is held, which contracts.
- **Operational** — the daily execution inside those rules: order handling, dispatch, replenishment, exception handling, day-to-day measurement.

A recommendation that only changes the tactical layer describes a policy nobody has to carry out. One that only changes the operational layer optimises inside a structure that may itself be the problem. Advice at both levels means: here is the rule we would change, **and** here is what the people executing it do differently on Monday.

The rubric's word for this is *"analyse operational / tactical processes"* — the phrasing is in the learning outcome itself.
