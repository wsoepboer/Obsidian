# Value Chain Analysis

Listed in pillar 1 alongside [[Supply Chain Mapping]], and the pairing is the point: the map shows **who and where**, the value chain shows **where value is added and where it leaks**.

The two answer different questions about the same network. Mapping asks *what does this chain look like*; value chain analysis asks *which activities actually create the value the customer pays for, and which merely add cost*. A step can be essential to the map and worthless in the value chain — which is exactly the kind of finding that yields a recommendation.

For the assignment it is the bridge from description to problem: the low-value, high-cost, or high-risk activities are where "more effective" or "more cost-efficient" improvements are found.
