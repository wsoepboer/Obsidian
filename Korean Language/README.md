## Ways to study

- **Linear** — work through [[10-Lessons/📌 Lessons by Date|lessons in order]], practicing between each.
- **Topic-based** — browse the [[20-Grammar/📌 Grammar Index|Grammar Index]] and deep-dive what interests you.
- **Vocabulary-first** — build words via the [[30-Vocabulary/📌 Vocabulary Index|Vocabulary Index]], then add grammar.
- **Practice-focused** — jump to [[40-Review/Conjugation Drills|drills]] and [[40-Review/Practice Questions|questions]], referencing grammar as needed.
