# Quick Reference

At-a-glance guide to essential Korean grammar and vocabulary.

---

## Particles (조사) — Essential

| Particle | Rule | Use | Example |
|----------|------|-----|---------|
| **은/는** | 받침 O→은, X→는 | Topic | 사과**는** 과일이에요 |
| **이/가** | 받침 O→이, X→가 | Subject | 사과**가** 좋아요 |
| **을/를** | 받침 O→을, X→를 | Object | 사과**를** 먹어요 |
| **도** | Noun + 도 | Also/too | 저**도** 좋아해요 |
| **과/하고** | 받침 O→과, X→와 | And/with | 형**과** 공부해요 |
| **의** | Noun + 의 | Possession | 선생님**의** 개 |
| **에게/한테** | After noun | To (person) | 엄마**에게** 전화 |
| **만** | After noun (replaces others) | Only/exclusivity | 동생**만** 학생이에요 |
| **에** | After place noun | At/to (place) | 학교**에** 가요 |
| **에서** | After place noun | In/at (place), action | 집**에서** 먹어요 |

See: [[20-Grammar/Particles/📌 Particle Overview|All particles]]

## 에 vs. 에서 — the verb decides

| Verb | Particle | Example |
|------|----------|---------|
| 있다 / 없다 / 가다 / 오다 | **에** | 저는 집**에** 가요 (I go home) |
| 먹다, 자다, 쉬다, 일하다, 공부하다… | **에서** | 저는 집**에서** 먹어요 (I eat at home) |

**Person, not place** → 에게/한테: 친구**에게** 전화해요 (never 친구에).
**Position words** go after the noun, then 에: 책상 위**에**, 회사 옆**에**.
**No 에** on 오늘 / 내일 / 어제 / 지금 / 올해: 내일 학교**에** 가요 ✓

See: [[20-Grammar/Particles/Location (에)|에]] | [[20-Grammar/Particles/Action Location (에서)|에서]]

## Verb Endings (어미) — Most Common

### Formal Polite: -습니다 / -습니까
```
받침 O: 좋습니다 / 좋습니까?
받침 X: 갑니다 / 갑니까?
```
*Most formal, shows respect*

### Informal Polite: -어요 / -아요
```
ㅏ,ㅗ vowel: -아요 (좋아요)
Other vowel: -어요 (먹어요)
Exceptions: 오 → 와요, 덥다 → 더워요, 좋아하다 → 좋아해요
```
*Common, conversational*

See: [[20-Grammar/Verb Endings/Formal Polite|Formal]] | [[20-Grammar/Verb Endings/Informal Polite|Informal]]

## Special: 좋다 vs. 좋아하다

| | Pattern | Meaning |
|---|---------|---------|
| **좋다** | S + 이/가 + 좋다 | X is good |
| **좋아하다** | S + O + 을/를 + 좋아하다 | I like X |

Examples:
- 사과**가** 좋아요 = Apples are good (to me)
- 저는 사과**를** 좋아해요 = I like apples

See: [[20-Grammar/Special Verbs/좋다 vs 좋아하다|Full explanation]]

## Numbers

### Sino-Korean (일, 이, 삼...)
Used for: **minutes, months, dates**
- Example: 십사분 (14 min), 육월 (June), 이십오일 (25th)

### Native Korean (하나, 둘, 셋...)
Used for: **hours**
- Example: 한 시 (1 o'clock), 두 시 (2 o'clock)

See: [[20-Grammar/Numbers & Time/Sino-Korean Numbers|Sino-Korean]] | [[20-Grammar/Numbers & Time/Native Korean Numbers|Native]]
