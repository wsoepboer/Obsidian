# Abbreviations & Symbols

Quick reference for notations used in these notes.

---

## Grammatical Terms

| Symbol | Meaning |
|--------|---------|
| **S** | Subject |
| **V** | Verb |
| **O** | Object |
| **받침** | Final consonant (support); determines particle/ending choice |
| **O** (in 받침) | Has a final consonant |
| **X** (in 받침) | No final consonant |
| **어미** | Verb/adjective ending |
| **조사** | Particle |
| **대화** | Dialogue / conversation |
