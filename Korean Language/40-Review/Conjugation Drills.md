# Conjugation Drills

Practice conjugating verbs and adjectives with different endings.

---

## -습니다 / -습니까 (Formal Polite)

Conjugate using **-습니다** (statement) and **-습니까?** (question):

1. 좋다 → \_\_\_ / \_\_\_ ?
   - Answer: 좋습니다 / 좋습니까?

2. 가다 → \_\_\_ / \_\_\_ ?
   - Answer: 갑니다 / 갑니까?

3. 먹다 → \_\_\_ / \_\_\_ ?
   - Answer: 먹습니다 / 먹습니까?

4. 듣다 → \_\_\_ / \_\_\_ ?
   - Answer: 듣습니다 / 듣습니까?

5. 좋아하다 → \_\_\_ / \_\_\_ ?
   - Answer: 좋아합니다 / 좋아합니까?

---

## -어요 / -아요 (Informal Polite)

Conjugate using **-어요/-아요**:

### Regular

1. 먹다 → \_\_\_
   - Answer: 먹어요

2. 가다 → \_\_\_
   - Answer: 가요

3. 좋다 → \_\_\_
   - Answer: 좋아요

4. 있다 → \_\_\_
   - Answer: 있어요

5. 많다 → \_\_\_
   - Answer: 많아요

### Irregular: ㅂ Irregular

6. 덥다 → \_\_\_
   - Answer: 더워요

7. 춥다 → \_\_\_
   - Answer: 추워요

### Irregular: 하다

8. 좋아하다 → \_\_\_
   - Answer: 좋아해요

9. 공부하다 → \_\_\_
   - Answer: 공부해요

10. 일하다 → \_\_\_
    - Answer: 일해요

---

## Negative Conjugations

Negate these sentences:

### Using 안

1. 저는 고기를 먹어요.
   - Answer: 저는 고기를 안 먹어요.

2. 우리는 학교에 가요.
   - Answer: 우리는 학교에 안 가요.

### Using 못

3. 나는 한국어를 해요.
   - Answer: 나는 한국어를 못 해요.

4. 시간이 있어요.
   - Answer: 시간이 없어요.

### Using 이/가 아니에요

5. 나는 선생님이에요.
   - Answer: 나는 선생님이 아니에요.

6. 이건 사과예요.
   - Answer: 이건 사과가 아니에요.

---

## Daily Practice Tip

- **Spend 10 min/day** on conjugation drills
- **Focus on one ending** per session
- **Write out the full conjugation** (not just the answer)
- **Say it aloud** to practice pronunciation
