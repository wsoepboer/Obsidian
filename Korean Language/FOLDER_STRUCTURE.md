## Navigation Tips

### Using Obsidian's Features

1. **Graph View**: See connections between grammar topics
2. **Backlinks**: Find all files linking to a concept
3. **Search**: Ctrl+Shift+F to search all files
4. **Quick Open**: Ctrl+P to jump to any file
5. **Outline**: See heading structure within a file

### File Naming Convention

- **📌** = Index/overview file
- **📍** = Home/entry point
- **All other files** = Content files
- **Folder prefixes** (00–50) = Organize by level/type
