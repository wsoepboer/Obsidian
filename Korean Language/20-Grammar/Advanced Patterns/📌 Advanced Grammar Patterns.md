## Quick Reference: When to Use

| Pattern | Function | Example |
|---|---|---|
| **-기** | make noun from verb | 걷기는 건강에 좋아요. (Walking is good for health.) |
| **-는 것 같다** | "seems/appears that" | 비가 오는 것 같아요. (Seems like it's raining.) |
| **-(으)ㄹ 수 있다** | "can/able to" | 수영할 수 있어요. (Can swim.) |
| **-아/어야 하다** | "must/have to" | 공부해야 해요. (Have to study.) |
| **-게 되다** | "come to/turn out to" | 한국에 살게 됐어요. (Ended up living in Korea.) |
| **-다고 하다** | report what someone said | 와온다고 했어요. (Said he was coming.) |
| **-고 있다** | action in progress | 먹고 있어요. (Am eating right now.) |
| **-아/어 있다** | resultant state | 앉아 있어요. (Seated/in sitting position.) |
